How a startup should enter — the playbook

Do not build another memory store or a better compactor; the clouds and model vendors own both. Enter as the neutral party that measures memory and context quality, give the harness away, and monetise the thing the measurement reveals: a write-gate and a policy-pinning layer that sit between any agent and any store. Land with measurement, expand into enforcement.

Where not to play

The problems section ranks pain; this one ranks entry. Compaction mechanics and tool bloat belong to the harness vendors: Anthropic shipped server-side compaction with custom instructions and pause-after-compaction in January 2026 (docs), OpenAI followed in February, and code execution cuts 150,000 tool tokens to 2,000 (Anthropic). IDE session memory is bundled everywhere. A hosted memory API is the lane with six funded entrants, no disclosed revenue and two hyperscalers billing for the same thing (AWS AgentCore since Oct 2025 and Google Memory Bank since Feb 2026); Letta's drift from runtime to Letta Code (pricing) shows what happens when a memory engine cannot find a standalone buyer. Vertical memory is deferred to wedge 5 as expansion after measurement, and portability is excluded because nobody pays for it yet (problems row 14).

The recommended wedge: measure first, then gate

Lead with wedge 1 and build wedge 2 on its findings, with wedge 3 as the enterprise expansion. Four reasons.

First, lowest platform risk. Model vendors do not grade third-party memory, and memory vendors cannot grade themselves credibly: Zep's critique shows a full-context baseline (~73%) beating Mem0's best configuration (~68%) on 16,000–26,000-token conversations, while Mem0 self-reports 92.5%, benchmark unspecified on Mem0's page and distinct from its 94.4% LongMemEval claim (Mem0). A neutral scorer is something every vendor needs and none can be.

Second, the budget line exists. AWS AgentCore since Oct 2025 and Google Memory Bank since Feb 2026 bill for memory (AgentCore pricing); Mem0 Pro is $249/mo, Zep Flex $1,250/yr. Anyone paying those bills can be asked what share is junk; #4573 says 97.8%, and the gate that fixes it is the recurring-revenue product.

Third, evals are funded. Braintrust's $80M Series B (SiliconANGLE, Feb 2026) and LangSmith prove the budget; the risk is they extend into memory metrics. So do not compete on tracing: ship as a scorer inside their traces and hold the asset they lack, a labelled corpus of real memory failures.

Fourth, it compounds. The harness shows which failure classes matter; the gate enforces them at write time; ConstraintRot shows pinning returns violations to 0% from 30% after compaction (38% when the constraint is dropped from the summary), and the sidecar that checks survival can re-inject. Each product sells to the same platform owner on evidence the previous one produced.

Pricing and open source

Open-source the harness, metric definitions and trace format under Apache-2.0 and keep them first-class; the first objection on Mem0's Show HN (2024) was whether the OSS version would stay supported, and it still is. Keep the hosted CI, failure corpus and learned gate rules proprietary: Supermemory's open clients around a closed engine.

Meter on evaluated episodes and gated writes, never on stored records; per-record pricing is the incentive that produced the junk. Proposed anchors: free under 1,000 episodes a month; a team tier at $200–500/mo beside Mem0 Pro ($249) and Zep Flex Plus (~$312); enterprise with SOC 2 Type II, audit logs, SSO and BYOC, which Zep's eight-person team cleared and Mem0 still gates behind sales (Mem0 pricing). Margin depends on judge tokens per episode, so track cost per episode from week one.

Distribution

Mem0 grew by being the default inside 25+ frameworks and an MCP server, not from its launch (integrations); AWS naming it exclusive Strands memory provider followed. Copy the mechanism with a scorer instead of a store:

  • Framework adapters first: LangGraph, OpenAI Agents SDK, Vercel AI SDK, Claude Agent SDK, CrewAI, and a Microsoft Agent Framework context provider, whose pluggable backends (1.0) make every store swappable and so measurable.
  • An MCP server so Claude Code or Cursor users can audit a Mem0 or Zep store from the editor; Zep already sells MCP seats, so the channel is proven.
  • The memory vendors as a channel: invite all six to submit to a public leaderboard with reproducible runs; vendors that lost the benchmark wars gain from a referee.
  • Observability platforms as hosts: ship as a Langfuse, Braintrust and LangSmith scorer rather than a rival dashboard.
  • Cloud marketplaces beside Memory Bank and AgentCore Memory, where the bill already exists.
  • Enterprise via security owners for the pinning sidecar: sell the audit trail and the multi-vendor case no single model vendor will serve.

First 90 days and what to watch

  1. Days 1–30: Apache-2.0 harness that replays recorded traces against Mem0, Zep, Cognee, Letta, Memory Bank, AgentCore and a filesystem-grep baseline; five metrics; GitHub Action.
  2. Days 15–30: publish the leaderboard with reproducible runs and launch on Hacker News, where both Mem0 and Zep launched.
  3. Days 31–60: hosted CI, three framework adapters, MCP audit server; ten design partners given free audits in exchange for failure traces.
  4. Days 61–90: write-gate beta (dedup, loop detection, PII, provenance) from design-partner findings; constraint-survival check for Anthropic and OpenAI compaction; pricing page live; first five paying teams.

Metrics, in priority order: episodes evaluated per week (the usage metric investors accepted for Mem0 and Cognee, not stars); share of runs on stores you do not own; vendor submissions to the leaderboard (target three of six); design-partner to paid conversion (target five of ten); junk rate in gated versus ungated stores against the 97.8% baseline; constraint survival after compaction against ConstraintRot's 0%/30%; time to first score under 30 minutes; judge cost per episode; net revenue retention once the gate ships.

Implications for a new entrant

  • The only durable position in this chain is the one no vendor can hold, the neutral measurer; start there even though the largest bills sit elsewhere.
  • Price on work done (episodes, gated writes), never on records stored, because per-record metering is the root cause of the junk you are selling against.
  • Distribution is framework adapters plus an MCP server, in that order; the launch post is a news hook, not a channel.
  • Treat evals platforms as hosts and memory vendors as submitters; the moment either sees you as a rival, the wedge narrows.
  • Hold compliance certs early: an eight-person team (Zep) owns the regulated lane because better-funded rivals gated it behind sales.
  • Do not touch compaction mechanics, tool loading or IDE session memory; the platform vendors shipped, and they iterate faster than you can.
