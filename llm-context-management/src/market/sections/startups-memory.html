Startup landscape I: the memory layer

Six funded startups (seven profiled, Memobase undisclosed) have raised about $51M of disclosed equity between them, and one of them, Mem0, holds most of the distribution: 61k GitHub stars, 186M API calls a quarter and an exclusive AWS channel. The rest differentiate on architecture (agent runtime, temporal graph, enterprise knowledge graph, user modelling). None discloses revenue, and vendor benchmarks do not reproduce.

Key numbersMem0: $24M raised (Oct 2025), 61,323 stars (Jul 2026), API calls 35M to 186M per quarter (Q1 to Q3 2025). Letta: $10M seed at $70M post-money (BigDATAwire, unconfirmed; Sep 2024). Four positioning camps

The cohort splits on where memory lives and who controls it.

  • OS-style agent runtime (Letta). Letta productises the 2023 MemGPT paper: the agent edits its own core, recall and archival memory through tools, and the company bills per stateful agent. It is the only vendor selling the agent rather than a memory endpoint. In 2026 its front door moved to Letta Code; letta.com/pricing now redirects to the Letta Code pricing page, and Ry Walker's teardown records a 42.5 percent Terminal-Bench score and an April 2026 desktop app. That is a tell: a pure memory runtime did not carry the company on its own.
  • Extraction layer, bolt-on API (Mem0, Supermemory, Memobase). These sit beside any stack: send messages, an LLM extracts facts, a vector store (plus an optional graph) serves them back. Mem0 meters add versus retrieve requests and claims up to 80 percent prompt-token savings (Sacra). Supermemory meters per 1K tokens and bundles connectors (Gmail, Notion, GitHub) and IDE plugins as tier differentiators (pricing). Memobase narrows the same idea to chatbot user profiles and event timelines with a sub-100ms online path.
  • Graph memory (Zep, Cognee). Zep's open-source Graphiti builds a bi-temporal knowledge graph with validity windows and retrieves without an LLM call, at a stated P95 of about 300ms (Zylos). Cognee's Extract-Cognify-Load pipeline ingests 38+ sources into a graph with 14 retrieval modes and plugs into Neo4j and Amazon Neptune; its buyers are regulated, knowledge-intensive organisations such as Bayer, not chatbot builders.
  • User modelling, reasoning-first (Plastic Labs' Honcho). Honcho stores messages and then reasons in the background about "peers" (people, agents, groups, projects), claiming 90.4 percent on LongMem S using a median 5 percent of context. It is the closest of the cohort to consumer personalisation and the furthest from a drop-in store: setup takes about 30 minutes (Postgres, Redis, an LLM key) against about 30 seconds for Mem0, per andrew.ooo's review.

A pure consumer-memory company is absent from the venture-backed set. Supermemory began as an open-source consumer "second brain" with 50k+ users at seed and pivoted to a developer API; SuperLocalMemory's 2026 Show HN pitches local, free memory for Claude users against hosted Mem0, which marks a privacy segment rather than a company.

Two gaps cut across the whole cohort. No company discloses revenue, ARR or a post-2024 valuation; Mem0's quarterly API calls and signups are usage, not dollars. And vendor benchmarks are discounted by buyers now that independent runs diverge by 20 points. A February 2026 Ask HN from a YC founder adds a product gap: Mem0 and Letta store facts and search them, but neither learned a repeated threshold correction (85 to 80 percent), and a second startup reported "hitting the same wall".

How much capital, and which signals to trust

Disclosed equity across the six funded startups (seven profiled, Memobase undisclosed) is about $51M (Mem0 $24M, Letta $10M, Cognee $7.5M, Plastic Labs $6M, Supermemory $3M, Zep $0.5M), before whatever Plastic Labs has sold under its Form D. For scale, one Postgres platform with vector support, Supabase, raised $100M at a $5B valuation in 2025 (VentureBeat). Memory is funded as a seed-to-A category, not yet as a platform, and the teams are tiny: Mem0 listed 10 employees in the YC directory, Zep 8 and Supermemory 13 on Tracxn.

Traction signals in order of reliability: named customers with a use case (Cognee and Supermemory publish them; Mem0 says "Fortune 500" without names); channel exclusivity (Mem0 inside AWS's Agent SDK since May 2025); metered usage growth (Mem0's API calls); then stars, which moved 50 percent in nine months for Mem0 and more than doubled for Cognee in five, and therefore say little on their own. Investor-side framing is consistent: Six Point Ventures segments Mem0 as bolt-on, Zep as facts-that-change and Letta as ground-up builds, and AgentMarketCap names Zep the only vendor with full GDPR, SOC 2 Type II and HIPAA coverage in 2026.

Implications for a new entrant

  • Distribution, not architecture, is what Mem0 has proven; secure a framework or cloud channel (CrewAI, Vercel AI SDK, an AWS-style exclusive) before arguing graph versus vector.
  • The open product gaps are preference learning from user corrections, deterministic no-LLM write paths (the Mnemora and Mnemosyne pitches) and reproducible evals; each is a narrower wedge than another general memory API.
  • Compliance packaging is a moat only Zep has fully built, and Letta lists no SOC 2 or on-prem option on its pricing page, so agents in finance, health and legal remain underserved.
  • Letta's move to a coding agent and Supermemory's connector bundling show that memory APIs drift into adjacent products within 18 months; plan the second product from day one.
  • Publish benchmark harnesses and seeds: after the 94.4 versus 73.8 percent Mem0 reproduction, an unreproducible number is a liability with technical buyers.
  • Expect $3M to $7.5M seed cheques unless you arrive with Mem0-scale usage; total disclosed capital in the category is about $51M, so model a seed-to-A path rather than a platform raise.
