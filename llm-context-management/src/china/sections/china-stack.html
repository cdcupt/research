CN The Chinese context-management stack

China's labs treat long context as an economics problem and publish the solution at every layer: attention compression (DeepSeek MLA→NSA→DSA→CSA/HCA), hybrid linear architectures (Qwen, Kimi, MiniMax), KV-cache-centric serving (Mooncake, now inside vLLM and SGLang), and a VC-funded memory-OS industry (MemOS). Because the flagship weights ship MIT/Apache, this stack is the substrate most open context research now builds on.

DeepSeek: attention compression as a pricing weapon

The through-line of DeepSeek's four attention generations is that each one converts a KV-cache saving into a public price cut. DeepSeek-V2 (May 2024, 236B/21B active, 128K context) introduced Multi-head Latent Attention (MLA), compressing the KV cache into a latent vector: 93.3% smaller cache and 5.76x higher max generation throughput than DeepSeek 67B — the same numbers anchored in the deep dive. Native Sparse Attention (Feb 2025) made sparsity trainable end-to-end and hardware-aligned; V3.2-Exp productionized it as DeepSeek Sparse Attention (DSA) on Sep 29, 2025, benchmarking on par with V3.1-Terminus while API prices dropped 50%+ effective immediately.

The V4 report (posted Jun 2026, per its arXiv ID 2606.19348; the Apr 24, 2026 InfoQ-CN headline below dates the launch earlier — an unresolved discrepancy) is the current end-state: hybrid Compressed Sparse Attention + Heavily Compressed Attention, two MoE sizes (V4-Pro 1.6T/49B active; V4-Flash 284B/13B), 1M-token context, 32T+ pretraining tokens. At 1M context, V4-Pro needs only 27% of V3.2's single-token inference FLOPs and 10% of its KV cache. The weights are MIT-licensed (per Wikipedia, accessed Aug 24, 2026), and Chinese coverage stressed first-time day-0 Huawei Ascend support alongside Nvidia (per InfoQ-CN headline, Apr 24, 2026). The pricing follow-through was again immediate: V4-Pro API permanently cut to a quarter of list (per Caixin headline, May 25, 2026).

Qwen: training-free scaling, hybrid linear attention, free platform memory

Alibaba's line started from serving, not architecture: Dual Chunk Attention (Feb 2024) decomposes attention into chunk-wise pieces so a model serves 100K+ tokens with no extra training. Qwen2.5-1M (Jan 2025) shipped the first open-weight 1M-token models (7B/14B) plus an open-sourced inference framework whose sparse attention and chunked prefill deliver a 3–7x prefill speedup at 1M tokens. Qwen3-Next-80B-A3B (Apache 2.0) is the architecture bet: 12 blocks of three Gated DeltaNet (linear) layers per one Gated Attention layer, 512-expert ultra-sparse MoE activating 10+1, 262,144 tokens native and ~1,010,000 via YaRN. By Aug 2026 the line had scaled to Qwen3.8-Max on Alibaba Cloud, marketed on context capacity (per CRN Asia headline, Aug 7, 2026), with NVIDIA itself publishing a GB300 NVL72 serving guide for Qwen3.8-2.4T-A95B (per NVIDIA blog headline, Aug 12, 2026).

Downstream, Alibaba gives the memory layer away: Bailian (百炼) long-term memory offers auto-extracted memory nodes and manual memory variables with free storage, and memory-content tokens "currently not charged" (docs, accessed Aug 2026) — a direct squeeze on standalone memory vendors.

Moonshot: co-designing attention and the serving fabric

Moonshot attacked both ends. MoBA (Feb 18, 2025) routes each query to a learned subset of context blocks — MoE applied to attention — and was already serving Kimi's long-context traffic at publication, with open code. On the serving side, Mooncake (Jun 2024, with Tsinghua) disaggregates prefill from decode around a distributed KV-cache pool; it won FAST 2025 Best Paper and lets Kimi handle 75% more requests within SLOs. The repo (6.4k stars, Aug 24, 2026) is now shared infrastructure: integrated by vLLM, SGLang, TensorRT-LLM, LMDeploy, LMCache and NIXL, running on NVIDIA, AMD, Huawei, AWS, Cambricon and Moore Threads silicon. Kimi K3 (Jul 27, 2026) stacks the model side: 2.8T-parameter MoE, 104B active (16 of 896 routed experts via Stable LatentMoE), 1M-token context on Kimi Delta Attention + Attention Residuals, ~2.5x scaling efficiency over K2. The paper itself concedes K3 trails Claude Fable 5 and GPT-5.6 Sol while beating every other model it evaluated — open weights one notch behind the closed frontier.

The memory-OS line and China's agent-memory research base

Above the models sits a distinctly Chinese layer: memory as an operating-system abstraction. The MemOS paper (Jul 2025; MemTensor 记忆张量 + SJTU collaborators) unifies plaintext, activation and parameter-level memory in a versioned MemCube unit. The Apache-2.0 repo reached 11.0k stars by Aug 24, 2026, self-reporting LoCoMo 88.83, LongMemEval 89.20 and 35.24% token savings vs commercial memory products, and shipped a DeepSeek Harness plugin on Aug 17, 2026. Commercially, MemTensor closed a ~RMB 100M (亿元) Pre-A in Jul 2026 reportedly backed by Huawei, Honor and SenseTime (per 新浪财经/品玩 headlines), selling a fully-local MemOS Lite for on-prem/信创 buyers with enterprise names like Trip.com, Haier and China Telecom on its site.

It is not alone: Prof. Hao Jianye's (郝建业, Tianjin University) learnable-memory (可学习记忆) startup closed three rounds in six months (per 36氪 headline, Aug 11, 2026; sizes unknown), and Shenzhen's MemoraX raised a $10M+ seed for "endogenous memory" (内生记忆), reaching cumulative 数亿元 by Aug 2026 (per 投资界/智东西 headlines). The research base skews the same way: the canonical agent-memory survey (Apr 2024) came from Renmin University's Gaoling School of AI with Huawei collaborators, and Chinese groups dominate the follow-on benchmark and taxonomy literature that products like MemOS cite.

Open weights as the substrate of global context research

The strategic effect is compounding. Every mechanism above — MLA, DSA, MoBA, DeltaNet hybrids, lightning attention — can be downloaded, ablated and reused under MIT or Apache terms, which is why Western efficiency papers benchmark against DeepSeek and Qwen rather than closed US frontier models (whose windows are discussed in the deep dive). The serving layer crossed over outright: Mooncake merged into vLLM, SGLang and TensorRT-LLM workflows, and NVIDIA now writes deployment guides for Qwen flagships. Day-0 Ascend support in V4 plus Mooncake's Huawei/Cambricon backends make the whole stack the first credible non-Nvidia long-context path.

Implications

  • Attention generations now arrive as price events: DSA cut DeepSeek's API 50%+ on launch day (Sep 29, 2025); V4-Pro went to a quarter of list in May 2026. Budget models should assume Chinese long-context inference keeps deflating.
  • KV-cache disaggregation is shared plumbing: Mooncake improvements propagate through vLLM/SGLang/TensorRT-LLM to every stack, including US ones — adopting it is an integration choice, not a rewrite.
  • Million-token experiments no longer require a frontier API contract: V4 (MIT), K3, GLM-5.2, MiniMax M3 and Qwen 1M models are all open-weight as of mid-2026.
  • Memory is China's next funded layer (three startups raised in 2026 alone), but platforms like Bailian price memory at zero — standalone vendors must win on portability and on-prem (信创) deployment, as MemOS Lite does.
  • Hardware bifurcation is real: day-0 Huawei Ascend support (V4) and multi-vendor Mooncake backends mean the Chinese context stack runs off-Nvidia; efficiency techniques tuned only for CUDA may not transfer back.
  • Caveat: open weights trail the closed frontier — Moonshot's own K3 paper places it behind Claude Fable 5 and GPT-5.6 Sol; the Chinese advantage is cost-per-token-of-context, not peak capability.
