Summary

The problems practitioners face now — and which are worth solving

Loud problems (compaction, tool bloat, session reset) are being solved natively; quiet ones (memory/retrieval evaluation, junk memory, policy loss after compaction, memory security) are open and budgeted.

Market structure, size and money

Money sits at the chain's edges: $12.5B model APIs, $19B apps, $1.5B all non-model infra. Six memory startups raised ~$51M with no disclosed revenue; analyst TAMs overstate.

Startup landscape I: the memory layer

Memory is a seed-to-A category (about $51M disclosed across seven startups); Mem0 owns distribution, others differentiate on architecture; nobody discloses revenue and vendor benchmarks do not reproduce.

Startup landscape II — retrieval, data stores, observability and agent tooling

Adjacent layers are crowded and consolidating; stores and gateways are being absorbed by incumbents. White space: context-quality measurement inside existing traces, plus tool and interaction-log retrieval.

Incumbent and platform dynamics — what is being commoditized

Platforms absorbed compaction, pruning and single-vendor memory in 2025-26; they will not build cross-vendor portability, neutral evaluation, governance or vertical memory, which is where defensibility lives.

The Chinese market for context and memory

China's memory/context layer is a real funded category — MemTensor's ~¥100M CVC-backed Pre-A leads four memory startups — but it is being commoditized in real time (platforms give memory away free, 1M-token open models cut API prices to a quarter of list) while state capital, xinchuang/dual-filing rules, and the Manus block wall the market off from US entrants in both directions: expect commoditization pressure via Chinese open source in your own stack, not head-to-head competition in China.

Reference startups: how they started and what it teaches

Winners shipped a free artifact, reported usage not stars, and raised 12-24 months later; benchmark overclaims, app drift, and framework bundling are the traps to avoid.

How a startup should enter — the playbook

Enter as the neutral measurer of memory and context quality, open-source the harness, then monetise a store-agnostic write-gate and policy-pinning layer; avoid stores, compactors and IDE memory.

The problems practitioners face now — and which are worth solving

The loudest complaints — compaction that forgets mid-task, tool schemas eating the window, sessions that reset — are exactly the ones Anthropic, OpenAI, Google and AWS shipped fixes for in 2025–26. The problems still open, and already budgeted for, are quieter: nobody can measure whether a memory or retrieval layer works, memory stores fill with junk, and compaction silently drops policy.

What breaks, by cluster

Compaction forgets. The most-reported failure in coding-agent trackers. In claude-code #10948 (Nov 2025) auto-compact fires mid-task with "no user control, no warning" and the summary "loses track of file modifications, intermediate decisions, specific technical details"; siblings show it dropping Skills (#13919), project instructions (#24460) and, by June 2026, not firing at all (#66144). Cline compacts below 200K on a 1M model (#9181). The ConstraintRot benchmark (1,323 episodes, 7 model families) finds safety constraints violated 0% in full context, 30% after compaction, up to 59% for some models.

Memory fills with junk and goes stale. A 32-day audit of a production Mem0 store (mem0 #4573) found 97.8% of 10,134 entries unusable: 3,200+ restated the system prompt, 315 were hallucinated profiles, 130 leaked secrets, and one hallucination was re-extracted into 808 entries. A stronger model "extracts more indiscriminately". Stale facts outrank fresh ones because scoring ignores recency (#4956); concurrent writes bypass dedup (#6531); nothing expires.

Nobody can tell whether it is working. Memory is "one of the most common sources of subtle, hard-to-reproduce failures" and RAG metrics "don't fully apply" (mem0 #5235, May 2026). Benchmarks cannot discriminate: on LoCoMo a full-context baseline (~73%) beats Mem0 Graph (~68%) on 16–26k-token conversations (Zep); a filesystem+grep agent scores 74.0% (lhl); Mem0 self-reports 92.5%, benchmark unspecified on Mem0's page and distinct from its 94.4% LongMemEval claim (Mem0). Production RAG shares the blind spot: "the system answers confidently. No error signal is returned" (DigitalOcean); one practitioner guide claims ~40% miss rates and 10–25% reranker gains (unverified; RAG guide).

Tokens, cache and bills are opaque. One 106-tool MCP server injects 54,600 tokens per initialisation (Layered, Jan 2026); Anthropic's example cuts 150,000 tokens to 2,000 with code execution (Anthropic, Nov 2025). Manus runs ~100:1 input:output over ~50 tool calls per task at a 10x cached/uncached price gap (Manus). Server-side state adds opacity: compaction is billed as a separate iteration excluded from top-level usage (docs); Azure customers cannot see what chained state adds per turn (Microsoft Q&A).

Security and governance lag accumulation. MINJA poisons memory with ordinary queries at over 95% success (NeurIPS 2025); memory security "cannot be retrofitted at retrieval or execution time alone" (Lin et al.); a 435-paper survey finds the field over-invests in accumulating state versus "governing, recovering, or relinquishing it" (Always-On Agents). Unlearned data flows back between parameters and memory (Agentic Unlearning); AgentCore events cannot expire under 7 days (Cloud Burn).

What the platforms have already absorbed

Anthropic shipped context editing and the memory tool (Sep 2025), code execution with MCP and tool search (Nov 2025), server-side compaction with a 150,000-token default trigger (Jan 2026) and 1M context at standard pricing (Mar 2026), and calls server-side compaction "the recommended strategy" (docs). OpenAI added Responses-API compaction (Feb 2026) and Agents SDK sandbox memory (Apr 2026). Google's Memory Bank (Jul 2025) "consolidates new memories with existing ones and resolves contradictions"; AgentCore Memory has been GA since Oct 2025; Windsurf and Claude Code bundle session memory.

What vendors have not shipped: compaction fidelity metrics (constraint pinning is a paper, not a product); a neutral benchmark (memory vendors grade themselves); write-path quality gates, audit trails, recency-aware conflict resolution and expiry; and enforceable security or deletion controls, which appear only in blogs (Mem0) and backlogs (semantic-router #1386).

Worth solving versus not

  • Worth a startup's time (rows 1–5). Eval and regression detection for memory and retrieval; silent-failure detection for RAG; write-path hygiene (quality gates, loop breaking, audit); a cross-vendor policy layer that survives compaction; memory security. Each has an existing budget line, a vendor that is the wrong party to grade or police itself, and production rather than benchmark evidence.
  • Features, not companies (rows 6–7). Cross-vendor cost attribution and retention governance are real but narrow; they belong inside an observability or governance product.
  • Not worth it standalone (rows 8–14). Better compaction, MCP slimming, coding-agent session memory, context-rot mitigation and memory consolidation are now native, free, or a model property. Lock-in is widely discussed but nobody is shown paying to fix it.

Implications for a new entrant

  • Sell measurement before mechanism: a memory and retrieval eval harness has no vendor substitute and a known budget holder.
  • Treat compaction and tool bloat as solved inputs; build on Anthropic and OpenAI server-side state rather than against it.
  • Position write-path hygiene as a gating and audit layer in front of Mem0, Memory Bank or AgentCore; metered vendors have no incentive to surface their own junk.
  • Open enterprise conversations with ConstraintRot numbers: 0% to 30% policy violations after compaction is a compliance story.
  • Enter memory security early but expect a 12–24 month sales lag; attack papers are ahead of incidents.
  • Avoid any pitch whose demo is "remember across sessions"; every IDE and SDK vendor ships that.

The value chain and where the margin sits

Five layers, with revenue concentrated at the top and bottom.

  • Model vendors (OpenAI, Anthropic, Google, Meta). Foundation-model APIs took $12.5B of 2025 enterprise spend (Menlo 2025). Vendors are moving down into context: OpenAI bought Rockset in June 2024 (Synthedia); Claude Code added auto-memory in late 2025 (Zylos).
  • Serving and infrastructure. Gateways (OpenRouter, Portkey, LiteLLM, Vercel) and embedding storage. OpenRouter's weekly tokens reportedly grew from 5T to 25T in the six months to May 2026 (Tech Times; not fetched). Storage is being absorbed by incumbents: MarketsandMarkets names Microsoft, MongoDB and Elastic the "star players"; MongoDB bought Voyage AI in February 2025 (SolvedByCode); vectors became a data type inside Oracle, Google and S3 (VentureBeat).
  • Context and memory layer (the subject of this report). Memory APIs: Mem0, Letta, Zep/Graphiti, Cognee, Supermemory, Plastic Labs' Honcho, Hindsight. Retrieval platforms: Contextual AI, Vectara, Ragie. Ingestion and web data: LlamaCloud, Unstructured, Firecrawl, Exa, Tavily.
  • Frameworks and tooling. LangChain/LangGraph: 90M monthly downloads, 35% of the Fortune 500 (LangChain); LlamaIndex: 3M monthly downloads (PR Newswire). Observability vendors (Braintrust, LangSmith, Arize, Langfuse) capture "prompts, tool calls, retrieved context" per agent step (SiliconANGLE).
  • Applications. $19B of 2025 spend (Menlo). Glean (~$300M ARR by May 2026 per Sacra) and Cursor are applications whose core product is context assembly; Cursor buys storage from turbopuffer, not a memory layer (Sacra).

What investors are betting on

  • Memory is the missing agent primitive. Pebblebed's Pamela Vagata on leading Cognee: "Agents need real memory to be real products" (Cognee); VentureBeat predicts memory becomes "table stakes" for operational agents in 2026 (VentureBeat).
  • A neutral layer gains value as model use fragments. 37% of CIOs run five or more models and switching costs rise with agentic workflows (a16z); Mem0's "open, neutral memory" pitch and its exclusive slot in AWS's Agent SDK express this (TechCrunch).
  • Context as the new system of record. a16z's Big Ideas 2026: "the system of record will finally start to lose primacy" (LinkedIn summary, secondary).
  • Observability is the monetisation point. Braintrust at $800M, LangSmith traces up 12x, Langfuse bought by ClickHouse: where context failures become visible, budgets already exist.
  • Counter-thesis: economics and incumbents. turbopuffer reached ~$100M ARR at roughly $0.02/GB on object storage against $3,600/TB/month RAM-era systems (Sacra); vectors are being absorbed into Postgres, MongoDB and Elastic.
  • Reality check. Context engineering is niche and only 16% of enterprise deployments are true agents (Menlo); the thesis runs one to two years ahead of the spend.

Implications for a new entrant

  • Do not size the company on the $6B "orchestration and memory" TAM; the pool for dedicated memory APIs was probably under $50M in 2025, so a seed plan must assume category creation, not share capture.
  • Capital flows to whoever owns the trace (observability) or the bytes (storage); attach a memory product to one of those rather than selling it standalone.
  • Distribution beats features: Mem0's AWS Agent SDK exclusivity shows that being the default inside a framework or cloud SDK is the channel; negotiate one before the Series A.
  • Model vendors will bundle basic memory; position on what they will not do: cross-vendor portability, temporal facts (Zep), regulated-industry deployment (Cognee at Bayer), audit and evaluation.
  • Stars do not convert by themselves: Mem0 has 61,000 stars and no disclosed ARR, while LangChain needed LangSmith to reach $1.25B, so design the paid surface from day one.
  • Sell to the 16% of deployments that are true agents (coding and support agents), where context failures already cost money, rather than to the prompt-and-RAG majority.

Four positioning camps

The cohort splits on where memory lives and who controls it.

  • OS-style agent runtime (Letta). Letta productises the 2023 MemGPT paper: the agent edits its own core, recall and archival memory through tools, and the company bills per stateful agent. It is the only vendor selling the agent rather than a memory endpoint. In 2026 its front door moved to Letta Code; letta.com/pricing now redirects to the Letta Code pricing page, and Ry Walker's teardown records a 42.5 percent Terminal-Bench score and an April 2026 desktop app. That is a tell: a pure memory runtime did not carry the company on its own.
  • Extraction layer, bolt-on API (Mem0, Supermemory, Memobase). These sit beside any stack: send messages, an LLM extracts facts, a vector store (plus an optional graph) serves them back. Mem0 meters add versus retrieve requests and claims up to 80 percent prompt-token savings (Sacra). Supermemory meters per 1K tokens and bundles connectors (Gmail, Notion, GitHub) and IDE plugins as tier differentiators (pricing). Memobase narrows the same idea to chatbot user profiles and event timelines with a sub-100ms online path.
  • Graph memory (Zep, Cognee). Zep's open-source Graphiti builds a bi-temporal knowledge graph with validity windows and retrieves without an LLM call, at a stated P95 of about 300ms (Zylos). Cognee's Extract-Cognify-Load pipeline ingests 38+ sources into a graph with 14 retrieval modes and plugs into Neo4j and Amazon Neptune; its buyers are regulated, knowledge-intensive organisations such as Bayer, not chatbot builders.
  • User modelling, reasoning-first (Plastic Labs' Honcho). Honcho stores messages and then reasons in the background about "peers" (people, agents, groups, projects), claiming 90.4 percent on LongMem S using a median 5 percent of context. It is the closest of the cohort to consumer personalisation and the furthest from a drop-in store: setup takes about 30 minutes (Postgres, Redis, an LLM key) against about 30 seconds for Mem0, per andrew.ooo's review.

A pure consumer-memory company is absent from the venture-backed set. Supermemory began as an open-source consumer "second brain" with 50k+ users at seed and pivoted to a developer API; SuperLocalMemory's 2026 Show HN pitches local, free memory for Claude users against hosted Mem0, which marks a privacy segment rather than a company.

Retrieval platforms: price competition and the "context engine" reframe

Glean is the scaled incumbent for feeding enterprise context to agents: Sacra estimates $300M ARR in May 2026, up from $208M at end-2025. Below it, Contextual AI (about $100M raised; HSBC and Qualcomm as early customers, sweep snippet, unverified) and Vectara ($73.5M) sell grounded RAG to regulated buyers, and integrator buyer guides now lead with compliance (Sphere). Pure managed RAG is already price-compressed: Ragie publishes $100–500/month tiers and reportedly poaches Vectara customers with discounted onboarding (Forage). Vectara open-sourced a RAG evaluation framework in April 2025 (sweep snippet, unverified) — a retrieval vendor moving into measurement. Onyx ($10M seed, 40+ connectors, open source) challenges Glean; LlamaIndex's capital goes to ingestion (LlamaParse), backed by 3M+ monthly downloads and 38,000 GitHub stars (sweep snippet, unverified).

Web data for agents is its own commoditising sub-market: Exa, Tavily and Firecrawl are benchmarked head-to-head (AIMultiple, eight APIs), and Tavily was reportedly acquired by Nebius in February 2026 (snippet, unverified). RAGFlow's year-end review captures the positioning shift: RAG is being reframed as "a Context Engine with intelligent retrieval as its core", with tool retrieval and memory over interaction logs named as new retrieval problems, and GraphRAG flagged for consuming "several to dozens of times more tokens than original text" (RAGFlow). Every retrieval vendor now calls itself a context platform.

Vector and graph stores: a data type, not a category

Four research houses put the vector-database market at $2.0–3.2B (2025/26; syndicated estimate, weak methodology) with 22–28% CAGRs (MarketsandMarkets $2.65B; GMI $2.55B; Research and Markets $3.02B), and MarketsandMarkets ranks Microsoft, MongoDB, Elastic, Google and AWS above the pure plays. VentureBeat's 2026 read is that vectors became a data type inside Oracle, Google databases and S3, PostgreSQL became the default for GenAI, and purpose-built vector-DB use cases will narrow. Incumbent M&A agrees: MongoDB bought Voyage AI (Feb 2025), Databricks bought Neon ($1B), Snowflake bought Crunchy Data ($250M) (VentureBeat).

turbopuffer is the counter-example. It keeps data in object storage with an NVMe cache, prices around $0.02/GB against RAM-era architectures, and reached roughly $100M annualised revenue in March 2026 (from $75M at end-2025) having raised under $1M of primary capital. Its largest customer is Cursor ("over a trillion chunks of code across more than 80 million namespaces"); Notion migrated 10B+ vectors in October 2024 and then dropped per-user AI charges (Sacra). The store that won inside coding agents sold economics, not features. Memory is the feature every store is adding: Sacra's Mem0 profile lists Pinecone, Weaviate, Chroma and Qdrant as "expanding into memory", Weaviate's cloud plans bundle "Agents" (sweep snippet, unverified), Zep's Graphiti temporal graph (28,000+ stars) is the graph-store route, and Cloudflare is listed as a memory provider alongside the startups (Developers Digest).

What got absorbed

Compaction. Anthropic's server-side compaction summarizes older history once input tokens cross a default 150,000 threshold (minimum 50,000), accepts custom summarization instructions, and is in beta on the first-party API, Bedrock, Google Cloud and Microsoft Foundry; the docs call it "the recommended strategy for managing context in long-running conversations and agentic workflows" (Anthropic). OpenAI's Responses API does the same through context_management.compact_threshold and a standalone /responses/compact endpoint, and with previous_response_id chaining the guidance is "do not manually prune" (OpenAI). Gateways pass it through (TrueFoundry) and frameworks are asked to expose it, not reimplement it (vercel/ai #12486, hermes-agent #526).

Pruning and tool bloat. Anthropic's context editing clears old tool results server-side (default trigger 100,000 input tokens, keep the last 3) and thinking blocks, reporting cleared_input_tokens in the response (Anthropic). Its November 2025 code-execution pattern loads tool definitions on demand and filters results in code, with a cited drop from 150,000 to 2,000 tokens, 98.7%, on one workflow (Anthropic Engineering). That was the product third-party MCP token optimizers sold (Layered measured a single 106-tool MCP server at 54,600 tokens per initialisation).

Memory. Google's Memory Bank (preview July 8 2025; billed from February 11 2026 at $0.25 per 1,000 events or memories) extracts, consolidates and resolves contradictions with Gemini (Google Cloud, pricing). AWS AgentCore prices short-term memory at $0.25 per 1,000 events, built-in long-term extraction at $0.75 per 1,000 records per month and retrieval at $0.50 per 1,000 (AWS). OpenAI's Agents SDK added Sessions (SQLite, SQLAlchemy, Redis, encrypted) and sandbox memory that distills prior runs into MEMORY.md files (OpenAI). Anthropic's memory_20250818 tool is generally available and client-side: Claude requests file operations under /memories and the developer owns storage (Anthropic).

The economic squeeze. 1M-token context reached GA on Opus 4.6 and Sonnet 4.6 on March 13 2026 at standard per-token pricing, and cache reads are discounted 90% (CloudZero). Both weaken the token-savings pitch memory vendors built on, such as Mem0's claimed "up to 80%" prompt reduction (Sacra).

Where the platforms stop

Each vendor's context artefacts are opaque and single-vendor by design. OpenAI's compaction item "is opaque and not intended to be human-interpretable" and is encrypted; Anthropic's compaction block is model-specific and billed as a separate iteration; Google's Memory Bank lives inside Agent Engine Sessions; AWS will not expire short-term events in under seven days (Cipher Projects). None exposes a transfer format. With 37% of enterprises running five or more models in production (a16z, May 2025), demand for a vendor-neutral layer is real and no model vendor has an incentive to supply it.

Evaluation is the second gap. Vendors benchmark themselves: Zep showed a full-context baseline of about 73% beating Mem0's graph variant on LoCoMo (Zep); an independent filesystem-plus-grep agent scored 74.0% (lhl); Mem0 users are asking for a memory-specific eval module because "regressions in memory behavior go undetected" (mem0 #5235). No platform publishes neutral staleness, conflict-resolution or update-propagation metrics.

Governance and security are the third. Memory poisoning through ordinary queries succeeds at over 95% (MINJA, NeurIPS 2025); defences are 2026 preprints. Platform memory offers no lineage, provenance or cryptographic integrity; a portable-memory protocol with provenance verification exists only as a May 2026 paper (arXiv).

Quality of what gets stored is the fourth. A March 2026 audit of a production Mem0 store found 97.8% of 10,134 entries were junk: "the extraction prompt is the bottleneck, not the model" (mem0 #4573). Platform memory ships generic extraction; vertical schemas are left to the application.

IDE and agent products: memory as a feature, not a layer

Windsurf's Cascade Memories persist across sessions (AI Made Tools); GitHub Copilot relies on a static copilot-instructions.md; Claude Code has CLAUDE.md, auto-compaction and, since late 2025, auto-memory (Zylos). The trackers show the feature is immature: Claude Code users report auto-compact firing mid-task with no warning (#10948), dropping Skills (#13919) and CLAUDE.md (#24460), and in mid-2026 failing to fire at all (#66144). Startups cannot own this surface: bolt-on memory products are reduced to "plug the vendor gap" tutorials published days after each vendor update (Hindsight, MemNexus).

What this means for defensibility

First, the mechanical layer is gone: compaction, pruning, tool-schema management and session stores have a six-to-twelve-month half-life before becoming an API flag or gateway pass-through. Second, the platforms' design choices create the whitespace: opaque artefacts, hosted metered storage and self-benchmarking suit a model vendor and fail a multi-model enterprise. Third, "developer-owned storage" no longer differentiates, because Anthropic's memory tool already puts storage on the client; a startup must differentiate on what the memory contains and how it is verified. Microsoft's pluggable context providers and Google's model-agnostic ADK give startups a connector slot, but a slot shared with Redis and Neo4j is distribution, not a moat. Portability and vertical memory are expansion after measurement, not the entry wedge: problems row 14 scores lock-in 6.0 because nobody pays for it yet.

Funding: state capital and CVC set the terms

The financing backdrop is structurally different from the US. USD funds' activity in China's primary market fell 84% in five years (Sina Finance, Jan 2026), replaced by ~¥300B of state-linked "hot money" (or100.cc, Aug 19 2026) and a reported ~$295B national AI buildout plan (Bloomberg via Reuters, Jun 9 2026). Enterprise requirements: xinchuang, dual filing, on-prem

Chinese enterprise demand is shaped by compliance, and it rewards local-first architectures. Government and SOE buyers procure under xinchuang (信创): iFlytek shipped a fully-domestic LLM appliance targeting party-government (党政) users (China Daily, May 11 2026), and vendor roundups make private deployment (可私有化部署) the key procurement criterion. This is why MemOS ships a zero-cloud Lite variant and why Dify's self-hosting is a feature, not a fallback — and it structurally locks out foreign SaaS memory vendors.

The Manus arc (verified via Wikipedia, Aug 24 2026) defines the regulatory wall. Implications

  • Whatever Chinese platforms bundle free — memory storage and memory tokens (Bailian, Aug 2026), Coze's 100-entry memory on-ramp (metered at production scale since Oct 15, 2025) — will face global price-to-zero pressure within roughly a year; a US memory vendor should price on retrieval quality and outcomes, never on storage or context length.
  • China is effectively unaddressable for a US context startup (双备案 filing, 信创 procurement, blocked M&A in both directions since Jan–Apr 2026). Do not build a China GTM; treat the separation as protection from the fastest commoditizers.
  • Chinese competition still arrives via open source: MemOS (Apache 2.0, 11k stars), Coze Studio, Dify (153.4k stars) and Mooncake (already inside vLLM/TensorRT-LLM) compete in US developers' stacks regardless of the market wall.   • MemTensor's Huawei/Honor/SenseTime cap table (Jul 2026) signals memory becoming a device/OS default in China; the analogous US move is early distribution partnerships with platform vendors before they build in-house.
  • The one segment Chinese buyers pay for — on-prem, private-deployment memory (MemOS Lite/Enterprise, iFlytek appliances) — maps directly to US regulated industries; ship a fully-local variant as table stakes.
  • Benchmark discipline: MemOS publishes LoCoMo 88.83 / LongMemEval 89.20 and a 35.24% token-savings claim against named commercial rivals — US memory products will be score-compared whether they participate or not.

Mem0: a complaint from a side project became the default memory API

Taranjeet Singh and Deshraj Yadav had built Embedchain (8,000+ stars) and a meditation app whose users complained that "the app doesn't remember"; Mem0 launched in January 2024 (TechCrunch). The Show HN on 4 Sept 2024 drew 201 points, and commenters already raised today's objections: open-source commitment, PII handled by prompting, memory bloat. A $3.9M seed led by Kindred went unannounced; the $20M Series A led by Basis Set was disclosed on 28 Oct 2025 with API calls up from 35M (Q1 2025) to 186M (Q3 2025), 80,000+ cloud signups and AWS naming Mem0 the exclusive memory provider for its Agent SDK. By 20 July 2026 the repository had 61,323 stars (Mnemoverse).

What worked: a three-line integration, 25+ framework integrations and an MCP server as distribution. What did not: credibility. Mem0 reports 94.4% on LongMemEval; an independent reproduction (Maximem, 27 May 2026) measured 73.8%, and a February 2026 Ask HN from a YC founder called it "key-value memory with semantic search" that cannot learn preferences.

Letta: paper, then open source, then cloud, then a drift toward an app

The MemGPT paper (UC Berkeley) appeared on 12 Oct 2023. The repository was renamed Letta on 23 Sept 2024 and a $10M seed led by Felicis was announced the next day, with angels including Jeff Dean and Clem Delangue (press release); BigDATAwire reported a $70M post-money valuation. Then the centre of gravity moved: Letta Code launched in December 2025 (42.5% on Terminal-Bench), a desktop app in April 2026, LettaBot was folded into Letta Code in May 2026, and letta.com/pricing now redirects to Letta Code pricing (Ry Walker, Letta docs). At 23,887 stars in July 2026 it is the smallest repository of the five despite the earliest research.

The lesson: research credibility buys a seed and strong angels, but a runtime billed per active agent is a harder sell than a drop-in API, and the company followed usage into coding agents.

Zep: a flat launch, then a second act in temporal graphs and compliance

Daniel Chalef's Show HN on 10 May 2023 earned 7 points for an open-source memory store. Tracxn shows one disclosed $500K seed (April 2024) and 8 employees in May 2026. The second act is Graphiti, an Apache-2.0 temporal knowledge-graph engine backed by the "Zep: A Temporal Knowledge Graph Architecture for Agent Memory" paper (arXiv 2501.13956, January 2025); it reached 28,981 stars by July 2026 and 30.2k by August, more than Letta. The lesson: a weak launch is survivable, an engine can out-star its company, and compliance is a wedge a small team can own while better-funded rivals gate it behind "contact sales".

Supermemory: consumer pull converted into a developer API

Dhravya Shah started Supermemory in summer 2024 as a consumer open-source "second brain"; it reached 10,000 stars and 50,000+ users, and companies asked for the underlying infrastructure. A $3M seed led by Susa Ventures with Browder Capital and SF1.vc was announced on 6 Oct 2025 (press reported $2.6M), with angels including Cloudflare CTO Dane Knecht and Sentry's David Cramer (company blog). The repository stood at 28,509 stars in July 2026, MIT-licensed clients around a closed engine; a free single-machine local binary shipped in June 2026. Pricing is token-metered from $19 to $399 a month with connectors as tier differentiators (pricing).

The lesson: a consumer tool is a cheap discovery channel for infrastructure demand, and open clients around a closed engine trade developer trust for defensibility.

Cognee: a later, graph-first, enterprise entrant from Berlin

Founded in 2024 by Vasilije Markovic, Cognee sells an Extract-Cognify-Load pipeline that turns 38+ sources into a knowledge graph. Pipeline runs grew from about 2,000 to over 1 million during 2025; it is live in 70+ companies including Bayer and the University of Wyoming; and it had 12,000+ stars and 80+ contributors when the $7.5M seed led by Pebblebed (Pamela Vagata, Keith Adams) with 42CAP and Vermilion was announced on 19 Feb 2026 (Cognee). Stars reached 28,786 by July 2026. Cognee publishes no LoCoMo or LongMemEval score.

The lesson: entering two years after Mem0 still produced a large seed by picking the structured, regulated-enterprise lane and reporting a usage metric (pipeline runs) investors accepted.

LangChain (adjacent): the framework that bundles memory as a feature

LangChain raised a $10M seed led by Benchmark (April 2023), a $25M Series A led by Sequoia at $200M (February 2024) and a $125M Series B led by IVP at $1.25B on 20 Oct 2025, with strategic backers including ServiceNow, Datadog and Databricks (LangChain, SiliconANGLE). It cites 90M monthly downloads, 35% of the Fortune 500 and a 12x rise in LangSmith trace volume. The library is free; the business is observability and evals. LangMem is its framework-native memory.

The lesson: the framework will bundle memory, so either become the default integration inside it (Mem0's approach) or be something a framework cannot be: a compliance-grade store, a temporal graph, a runtime.

Implications for a new entrant

  • Ship a free artifact first and expect 12 to 24 months before a priced round: Mem0, Supermemory and Cognee all followed that lag.
  • Report usage, not stars: the rounds cited API calls per quarter (Mem0) and pipeline runs (Cognee), while the team that led with research (Letta) has the fewest stars today.
  • Do not lead with a vendor benchmark nobody has reproduced; Mem0's 94.4% against Maximem's 73.8% is now quoted in every comparison.
  • Pick a billing unit that matches the buyer: requests (Mem0), credits (Zep), active agents (Letta) or tokens (Supermemory) each signal a different customer.
  • Compliance (SOC 2 Type II, HIPAA BAA, BYOC, EU DPA) is a wedge an 8-person company owns today; regulated buyers pay for it before they pay for benchmark points.
  • Assume frameworks and platforms will bundle memory (LangMem, Cloudflare, Claude Code auto-memory); be the default integration inside them or be structurally different.

The recommended wedge: measure first, then gate

Lead with wedge 1 and build wedge 2 on its findings, with wedge 3 as the enterprise expansion. Four reasons.

First, lowest platform risk. Model vendors do not grade third-party memory, and memory vendors cannot grade themselves credibly: Zep's critique shows a full-context baseline (~73%) beating Mem0's best configuration (~68%) on 16,000–26,000-token conversations, while Mem0 self-reports 92.5%, benchmark unspecified on Mem0's page and distinct from its 94.4% LongMemEval claim (Mem0). A neutral scorer is something every vendor needs and none can be.

Second, the budget line exists. AWS AgentCore since Oct 2025 and Google Memory Bank since Feb 2026 bill for memory (AgentCore pricing); Mem0 Pro is $249/mo, Zep Flex $1,250/yr. Anyone paying those bills can be asked what share is junk; #4573 says 97.8%, and the gate that fixes it is the recurring-revenue product.

Third, evals are funded. Braintrust's $80M Series B (SiliconANGLE, Feb 2026) and LangSmith prove the budget; the risk is they extend into memory metrics. So do not compete on tracing: ship as a scorer inside their traces and hold the asset they lack, a labelled corpus of real memory failures.

Fourth, it compounds. The harness shows which failure classes matter; the gate enforces them at write time; ConstraintRot shows pinning returns violations to 0% from 30% after compaction (38% when the constraint is dropped from the summary), and the sidecar that checks survival can re-inject. Each product sells to the same platform owner on evidence the previous one produced.

Pricing and open source

Open-source the harness, metric definitions and trace format under Apache-2.0 and keep them first-class; the first objection on Mem0's Show HN (2024) was whether the OSS version would stay supported, and it still is. Keep the hosted CI, failure corpus and learned gate rules proprietary: Supermemory's open clients around a closed engine.

Meter on evaluated episodes and gated writes, never on stored records; per-record pricing is the incentive that produced the junk. Proposed anchors: free under 1,000 episodes a month; a team tier at $200–500/mo beside Mem0 Pro ($249) and Zep Flex Plus (~$312); enterprise with SOC 2 Type II, audit logs, SSO and BYOC, which Zep's eight-person team cleared and Mem0 still gates behind sales (Mem0 pricing). Margin depends on judge tokens per episode, so track cost per episode from week one.

Distribution

Mem0 grew by being the default inside 25+ frameworks and an MCP server, not from its launch (integrations); AWS naming it exclusive Strands memory provider followed. Copy the mechanism with a scorer instead of a store:

  • Framework adapters first: LangGraph, OpenAI Agents SDK, Vercel AI SDK, Claude Agent SDK, CrewAI, and a Microsoft Agent Framework context provider, whose pluggable backends (1.0) make every store swappable and so measurable.

  • Observability platforms as hosts: ship as a Langfuse, Braintrust and LangSmith scorer rather than a rival dashboard.
  • Cloud marketplaces beside Memory Bank and AgentCore Memory, where the bill already exists.
  • Enterprise via security owners for the pinning sidecar: sell the audit trail and the multi-vendor case no single model vendor will serve.

  • The only durable position in this chain is the one no vendor can hold, the neutral measurer; start there even though the largest bills sit elsewhere.

The Dec-2024 cache product is being retired into a standard API

Volcano Ark's dedicated 上下文缓存 (Context API) — the product both sweeps surfaced from Dec 2024 — is now marked 待下线 ("pending offline") in Ark's historical docs (page updated Aug 24, 2026; exact shutdown date not published — unknown). Its replacement is caching folded into the Responses API, which extends caching from text-only to multimodal inputs (text, image, video) and tool-call information. The current context-caching guide (updated Aug 24, 2026) describes a two-mode system: implicit caching — automatic, cannot be disabled, no storage fee, hit not guaranteed, minimum 1,024-token cache block, default-on for doubao-seed-2.0-and-later and doubao-seed-code models — and explicit caching (Session cache and prefix cache) — deterministic hits, configurable expiry via expire_at up to a hard cap of 7 days, storage billed hourly from creation, prefix cache minimum 256 tokens. The pattern matches the US trajectory: the standalone "context product" of 2024 had a roughly 18-month half-life before being absorbed into the standard inference API.

Evaluation vendors: near the wedge, not on it

The four eval vendors sit closest. Patronus AI lists "agentic memory with context windows" among the agent behaviours it evaluates and states a $50M Series B; its RL environments and digital world models point its roadmap at agent training signal rather than memory stores. Galileo frames everything as "offline evals become production guardrails" with 20+ packaged evaluators and distilled Luna judges; that is the gate of wedge 2 built on generic metrics, not memory-specific ones. Confident AI (YC W25, seven staff) is the distribution threat: DeepEval reports 3 million monthly downloads and 2 million evaluations a day, and its model is "write custom metrics locally, compare on the cloud", which is the shape a memory metric pack would take. Ragas, at 15.4k stars, still lists agent evaluation as "coming soon" and monetises through consulting.

None of the four pages names recall after update, staleness, update propagation, conflict resolution or constraint survival, the metrics users asked Mem0 for in issue #5235 (May 2026) and the ones wedge 1 is built on. That absence is the finding: the budget and the host surfaces exist, the memory-specific content does not.

Frameworks that bundle memory

Mastra is the clearest case of a framework selling memory as a feature rather than a product: YC W25, 30 staff, a $22M Series A in April 2026, with memory, RAG and evals inside one TypeScript package. For a memory API it is platform risk of the kind landscape II flagged for LangMem; for a neutral evaluator it is a submitter, because a framework with built-in evals wants to show its memory holds up against external stores. Langbase could not be checked within the cap and is recorded as unknown.

MemOS, from Shanghai-based MemTensor, is the one Chinese entrant verified. Does this change the wedge-1 recommendation?

No, but it changes two cells in the GTM table. The test was whether a funded competitor already sells neutral, store-agnostic memory-quality CI. None was found: the funded parties are eval platforms with generic agent metrics (Patronus, Galileo, Confident AI), a framework that bundles memory (Mastra), and memory vendors that publish their own scores (MemOS, Hindsight, Mem0, Zep). The "who is near it" cell for wedge 1 should read Patronus, Galileo, Confident AI/DeepEval and Ragas plus the vendor leaderboards, and the host list should add DeepEval alongside Langfuse, Braintrust and LangSmith. The risk that moves is absorption speed: DeepEval's plugin model means a memory metric pack can be copied in weeks, so the durable asset is the replay harness across stores and the labelled corpus of real memory failures, not the metric definitions. LoCoMo-Plus and the Always-On Agents protocol make the same case academically: string-match benchmarks miss state mutation and stale-preference reuse. Patronus is the one to watch: a $50M company that already says "agentic memory" can fund the corpus if it decides to.

Implications for a new entrant

  • Add Patronus, Galileo, Confident AI/DeepEval and Ragas to wedge 1's "who is near it" cell and re-score platform risk from the eval side, not only the model-vendor side.
  • Ship the first memory metrics as a DeepEval and Ragas plugin as well as a Langfuse or Braintrust scorer; DeepEval's 3 million monthly downloads is the cheapest distribution on the list.
  • Recruit MemOS and Mastra as submitters in the first public replay: both have published claims (LongMemEval 89.20; bundled memory) they would want independently confirmed.
  • Do a short docs check of DeepEval's conversational metrics and Patronus's Percival before the seed deck; if either already scores staleness or update propagation, lead with constraint survival and cross-store replay instead.
  • Skip consumer and visual memory: Limitless's exit to Meta and Memories.ai's device partnerships show those are platform features and hardware channels, not a startup wedge.
  • Finish the YC W25 to S26 enumeration (three batches, roughly 500 companies) before fundraising; this addendum could not do it.
